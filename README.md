# task-tracker-bot

Телеграм-бот-трекер задач с расширяемой системой тегов (aiogram 3 + SQLite).

## Запуск

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy config.example.py config.py   REM и заполнить BOT_TOKEN + OWNER_USERNAME
.venv\Scripts\python bot.py
```

## Что умеет

- Задачи: список страницами по 9, создание, правка названия/описания,
  отметка «выполнена», софт-удаление.
- Теги: имя + эмодзи + описание + флаг `needs_description` (с ним при
  прикреплении тега к задаче описание связки обязательно).
- Связка задача-тег со своим описанием (режется до 100 символов).
- Доступ: владелец (`OWNER_USERNAME` в `config.py`) + список допущенных
  @юзернеймов в БД. Добавлять может любой допущенный, убирать нельзя.

Всё управление — inline-кнопками, бот редактирует одно сообщение-экран.
База — `tasks.db` рядом с ботом, создаётся сама при первом запуске.
